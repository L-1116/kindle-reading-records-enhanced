Kindle 原生阅读时长“阅读记录”v9.6.3-optimized 稳妥提速版
========================================================

本优化版基于 v9.6.3，只调整 Dashboard 显示层和覆盖升级安全性。
native-reading-time-daemon.sh、计时规则和 reading-time.tsv 数据格式均未改变。

优化版重点
----------
- 外层包名为 kindle-native-reading-records-v9.6.3-optimized，但复制到 Kindle
  根目录后的结构仍是 RUNME.sh + native-reading-time-package/。
- 已安装原始 v9.6.3 时可直接覆盖后执行 ;log runme，无需卸载。
- 安装器在完整暂存和校验后才停服务，并以临时文件和原子重命名切换程序。
- 首次升级会在不存在时创建 reading-time.tsv.bak；已有备份永不覆盖。
- 成功安装后 /mnt/us/reading-time/VERSION 内容为 9.6.3-optimized。
- Dashboard 使用一次会话专属的 /tmp 缓存，退出后删除，不增加后台任务。
- cc.db 只在首次打开“阅读书籍”Tab 时读取；仅看累计/每日时不会访问。
- Lua 将日历、柱状图和进度图形合成为 PGM 区域，显著减少 FBInk 启动。
- 日期选择只更新月历和详情区域；重复 Tab 和边界翻页不会重绘。
- 新渲染器失败时自动切换到随包保留的原始 v9.6.3 Dashboard。
- 首次进入保留 GC16，普通操作优先局部 GC16_FAST，每 6 次有效绘制清残影。

后台不变保证
------------
- 原始与优化包中的 native-reading-time-daemon.sh SHA256 均为：
  53C2B0472B758E0C1620835E6F8F2D26BA11D04122D982795309FEBCFE81D0EC
  （该值由电脑端离线测试计算，Kindle 安装器不会调用 sha256sum。）
- Kindle 安装器使用 cmp 做三次逐字节比较：载荷对当前已安装 daemon、
  暂存 daemon 对已验证载荷、最终安装 daemon 对已验证载荷。
- 未新增 daemon、定时任务、后台轮询或常驻缓存刷新进程。
- Dashboard 未打开时，后台进程、轮询频率和功耗行为与 v9.6.3 完全相同。

安装 / 覆盖升级
---------------
本优化包仅支持从已正常安装的原始 9.6.3 原地升级；如果找不到当前 daemon，
安装器会在创建暂存目录、停止服务和替换文件之前安全退出。

1. 将 RUNME.sh 和 native-reading-time-package 文件夹复制到 Kindle 根目录并覆盖。
2. 安全弹出并断开 USB。
3. 在 Kindle 首页搜索栏输入：;log runme
4. 安装器成功后会恢复 native-reading-time 服务并写入 VERSION。

测试日志
--------
- Dashboard 的 dashboard-launch.log 会记录每次有效操作的耗时、FBInk 调用数、
  渲染器路径及是否回退，格式以 METRIC 开头。
- 真机对比表和离线验证结果见 OPTIMIZATION-TEST-REPORT.md。
- 仅供回退测试：从终端以前台环境变量 DASHBOARD_RENDERER_FORCE_FAIL=1
  启动阅读记录，优化器会失败一次并切换到原始 v9.6.3 界面。

以下保留原 v9.6.3 版本说明。
-----------------------------

v9.6.3 书名归一化
----------------
- 同一个有效书籍编号出现“编码名称”和正常书名时，只显示一条合并后的记录。
- 合并后的累计时长为该编号全部历史记录之和，优先显示可读书名。
- “unknown”编号仍按书名分别统计，避免把无法识别的不同书籍错误合并。
- 每日详情、阅读书籍页面和文字统计报告采用相同的归一化规则。
- 不重写 reading-time.tsv，不删除或迁移历史数据，也不改变计时规则。

v9.6.2 界面性能优化
------------------
- 普通切页使用较快的 GC16_FAST 非闪烁刷新；首次打开及每6次绘制执行一次 GC16 全屏清残影。
- 静态背景已经覆盖完整界面，切页时不再额外清白整块物理屏幕。
- “每日时长”由每次最多扫描统计文件31遍改为一次性读取整月数据。
- “累计时长”把累计、阅读天数和月度柱状图合并为一次数据扫描。
- 后台计时守护进程、数据格式、安装器和触摸安全机制均未改变。

v9.6 计时修正
------------
- 只要 Kindle 原生书籍阅读器处于前台且屏幕为亮屏状态，就持续计入当前书籍的阅读时长。
- 返回书库、切换到其他应用或锁屏时，立即停止累计并保存。
- 切换书籍时先保存上一本文档，再开始记录新书。
- 删除 PC:TS、弹窗变化和“10分钟无活动暂停”判断，避免持续翻页却在10分钟后被错误暂停。
- 不监听翻页和触摸，不独占输入设备，也不会改变 Kindle 的翻页行为。
- 书停留在阅读页面但没有实际阅读时，只要屏幕仍亮着，该段时间也会被计入；自动休眠后停止。
- 保留约5秒一次的检测、约90秒批量写入、跨午夜拆分以及进入/退出边缘补偿。
- 安装升级不会清空 reading-time.tsv；旧版漏记的历史时长无法自动恢复。

待执行五：通用界面适配
----------------------
- 保留 1272×1696 作为统一设计坐标，打开界面时自动读取当前 Kindle 的实际屏幕尺寸。
- 背景、动态文字、日历、柱状图和书籍进度条按同一比例缩放并居中，不拉伸变形。
- 点击位置使用与界面完全一致的反向坐标换算，按钮和实际显示保持对齐。
- 自动寻找触摸屏输入设备；仍保留 /dev/input/event1 作为旧设备兼容回退。
- 每次打开后会生成 reading-time/display-layout.txt，方便反馈不同机型的适配结果。
- KPW6 的 1272×1696 原布局保持 1:1；较小或比例略有不同的竖屏会自动缩放并留白居中。
- 自适应 UI、历史数据格式和真实书籍进度读取保持不变；后台计时规则已在 v9.6 改为“阅读器前台且亮屏”。
- 本版为跨尺寸测试版；已知 KPW6 基础兼容，其他机型仍需实机验证，不代表所有固件均可安装。

实机验证基础
------------
- KPW6 / Kindle 5.19.5 / ARMv7 armhf。
- 使用 Véra/KPM 环境自带的系统级 FBInk：/var/local/kmc/bin/fbink。
- 实机探针确认该 FBInk 为 1.25.0，OpenType=Yes、Image=Yes，PNG 解码测试通过。
- 不再引用 /mnt/us/koreader/fbink 或 KOReader 字体；KOReader 不安装或被删除也不影响本插件。

新版界面
--------
- 动态文字统一使用随包附带的 Noto Sans CJK SC，覆盖中文、数字和常用标点。
- 日历日期下方不再显示细小的分钟数；当天有阅读时只显示一个小黑点。
- 每日时长页面压缩月历区域并扩大当日详情区域，比例更接近最初 UI 样板。
- 阅读书籍页面恢复为一个大圆角卡片内显示五行书籍，更接近最初 UI 样板。
- 三张 1272×1696 竖屏 PNG 作为设计底稿，运行时只做等比例缩放，不会横向拉伸变形。
- 平滑圆角卡片、黑底白字选中标签、适中字号和统一留白。
- 累计时长：总时长、阅读天数、日均、年份切换和每月柱状图。
- 每日时长：月份切换、月历、黑底白字日期高亮、当日书籍明细。
- 阅读书籍：一个大圆角面板内显示五本书、真实进度状态、上一页和下一页。

真实书籍进度
------------
- 不再用“各书阅读时长比例”冒充书籍完成进度。
- 打开“阅读记录”时，从 cc.db 的只读快照读取 p_percentFinished，并按完整书名与计时记录匹配。
- 阅读书籍页面显示真实百分比和对应进度条；没有匹配到的条目显示“暂无进度”。
- 进度只在打开界面时读取一次，不加入后台轮询，不增加日常计时耗电。
- 真实进度读取已由阅读记录界面内部完成，因此不再附带诊断探针。
- 安装时会清理书库中旧的“书籍进度探测.sh”和“阅读页数探测.sh”。

保留内容
--------
- 保留自适应轮询：亮屏时约5秒检查一次，锁屏时降低频率并等待系统唤醒事件。
- 保留 /mnt/us/reading-time/reading-time.tsv，不清空历史数据。
- 不启用 eatTapMode 1，不使用 EVIOCGRAB，不独占触摸设备。
- 左上角“退出”返回 Kindle 书库，不自动退出。

安装
----
1. 解压本压缩包。
2. 将 RUNME.sh 和 native-reading-time-package 文件夹复制到 Kindle 根目录并覆盖。
3. 安全弹出并断开 USB。
4. 在 Kindle 首页搜索栏输入：

   ;log runme

5. 等待约 10 秒，在书库打开“阅读记录.sh”。

注意
----
- 本版依赖 Véra/KPM 已安装的系统级 FBInk，不依赖 KOReader。
- 随包字体 Noto Sans CJK SC 依据 SIL Open Font License 1.1 分发，许可证安装于 reading-time/fonts/FONT-LICENSE.txt。
- 若将来卸载或损坏 Véra/KPM 的 /var/local/kmc/bin/fbink，界面将无法打开，但后台数据不会丢失。
