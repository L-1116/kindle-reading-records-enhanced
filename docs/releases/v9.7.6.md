# Kindle 阅读记录 v9.7.6｜多固件兼容版

## 1. 版本介绍

适用于已越狱 Kindle 的本地阅读记录插件，提供月历热力、每日与累计统计、阅读书籍、本地封面、月份及单书详情。本页面集中提供已验证的 Standard 安装包，按固件、越狱方式与机型选择；验证范围不等于所有设备均已测试。

## 2. 本次更新

- 相较 9.7.5 正式兼容版 V3，5.19 Vera 修复横屏阅读后进入插件时的白屏，保留原地升级及历史数据。
- 5.20.1 Vera 延续已验收的计时服务恢复、启动链优化、两文件安装及安全迁移；当前原包含 test2 设备识别修复，内部身份如实保留。
- 5.18 SpringBreak 提供 KPW4 / 5.18.1.1.1 专用适配；正常使用期间每次会话约 120 秒自动退出，也可主动退出。
- 发布结构改为单一正式版本页面；本次迁移仅规范外层 Assets 名称、记录来源与校验，不修改已验证安装包内容。

## 4. 安装与升级教程

先备份 Kindle 的 `reading-time` 文件夹。解压所选 ZIP 一次，将得到的脚本与 TAR 一起复制到 Kindle `documents`；不要再解压 TAR。安全弹出后点击书库“安装阅读记录”。旧普通版使用相同步骤原地升级，保留原数据，无需先卸载。打开“阅读记录”，确认历史和新增计时正常，再执行安装文件清理。

各包的真实文件名和入口要求如下：

- **5.20.1（保留 5.17 / 5.18 / 5.19 及 GC16 兼容路径，未据此追加实机结论） / vera**：`reading-records-v4-install.sh` + `阅读记录安装数据.tar`。需已有可用的 SH Integration 书库 Scriptlet。 清理入口：**确认无误之后，再点这个**。

- **5.19.x / vera**：`reading-records-9.7.6-install.sh` + `reading-records-9.7.6-data.tar`。需已有可用的 SH Integration 书库 Scriptlet。 清理入口：**安装好之后，确认无误了再点这个**。

- **仅 5.18.1.1.1 / springbreak**：`reading-records-9.7.6-install.sh` + `reading-records-9.7.6-data.tar`。需已有可用的书库 Scriptlet 执行支持；这是此 KPW4 的已确认入口，不推广到其他 SpringBreak 环境。 清理入口：**安装好之后，确认无误了再点这个**。

未配置相应书库脚本执行支持的设备不能直接使用这些简易包；其他越狱环境须先独立确认其安装入口，不假定支持相同步骤。

## 5. 注意事项

- 从 Assets 下载匹配环境的安装 ZIP；GitHub 自动生成的 **Source code (zip / tar.gz) 不是 Kindle 安装包**。
- 升级保留阅读历史、配置与封面缓存；不要手动删除 `reading-time`。清理不是卸载，归属不明的文件及必要回滚资源应保留。
- 实机成功仅限表内所列证据，自动化测试不能替代设备验证。失败时保留安装文件和备份，通过仓库 Issues 提供机型、固件、越狱方式、步骤及已有错误信息；异常日志仅用于售后，不要求普通用户运行命令或选择 runtime。
