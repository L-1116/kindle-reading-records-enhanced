# 9.7.5-测试版

- 增加 EPUB/MOBI 本体封面按需提取；PDF 继续复用 Kindle 已有缩略图，没有缩略图时显示默认封面。
- “累计时长”和“阅读书籍”增加“全部”范围。
- 启动器图标改为 600×960 的 5:8 竖版封面。
- 修复月历底部横线靠近外框，以及阅读书籍列表外框断角、粗细不统一的问题。
- 保持每页 3 本书、阅读进度、日期详情、单书详情和现有阅读统计数据格式不变。
- 增加独立的“阅读记录卸载” Scriptlet；Scriptlet、KUAL 和兼容动作统一调用 manifest 驱动的安全卸载核心，默认保留历史、备份、配置和未知文件。
- 安装器与卸载器位于同一个 ZIP；卸载后保留安装入口和 payload，可直接重装并继续读取原历史。
