# Kindle 阅读记录 v9.8.1

本次发布 **9.8.1-5.20-vera Standard 普通版**。已确认的实机环境为 **KPW6（Paperwhite 12 代）/ 固件 5.20.1 / Vera 越狱**，需已具备可用的 SH Integration 书库脚本支持。下文另列青春版 test9 启动确认；除此之外的机型、固件和越狱组合尚未完成本版验证，**不适用于 KS（Kindle Scribe）**。

## 2026-10-19：v9.8.1 同版本触摸兼容修复

修复同时报告 `KEY_POWER` 的直接手指触摸屏被误判为按键、打开后返回书库的问题。修复依据输入能力生效，不限定 Goodix 名称或 event 编号。笔、传感器、触摸板及多个同分触摸候选仍按安全规则排除。

用户已确认 **Kindle 青春版 2024 / 5.20.1 的 test9 实际启动成功**。下列正式包由该 test9 转为同版本正式身份，触摸、UI、坐标、计时和休眠运行代码逐字节一致；身份恢复及同版本覆盖安装经离线核验。既有 KPW6 test8 的实机证据继续保留，这不等于所有非 KS 机型均已实测。

插件版本仍为 **v9.8.1**，本次是 Bug 修复，无需先卸载：下载下方同名正式 ZIP，按原步骤覆盖安装。历史数据、配置及图片保留。

## 新功能与改进

1. **为暂无封面的书籍添加自定义图片**：支持通用替代封面，也可给每本书指定专属封面。历史书籍列表改为双列卡片，每页 10 本，并显示原始、专属、通用或暂无封面的当前状态。
2. **新增设置界面**：可直接在插件内管理计时与自定义封面选项。
3. **自定义无操作计时上限**：可设置连续 1～1440 分钟无触摸后暂停计时，再次触摸后恢复，减少忘记翻页时的误计时。此选项可关闭；触摸会重新开始无操作计时，并非每次翻页都固定计入所设时长。
4. **更新累计时长与阅读书籍 UI**：优化文字居中、星期标签和分页排版。阅读书籍每页仍为 3 本，历史书籍每页 10 本；两页均可点击底部带下划线的页码，直接选择目标页。页数较多时分组显示。
5. **修复插件界面无法熄屏的问题**，改善插件停留、休眠与恢复行为。

此外，安装器会直接创建 `reading-time/custom-covers/` 图片目录，全新安装、升级与修复均无需先启动插件或开启封面开关。已有图片、专属关联、阅读历史和配置保留；目录路径被普通文件或符号链接占用时明确报错，不覆盖用户内容。

## 自定义封面使用方法

1. 安装后通过 USB 打开 Kindle 的 `reading-time/custom-covers/`，复制 JPG / PNG 图片到此目录。
2. 打开插件“设置 → 自定义缺失封面”，开启功能并选择通用图片；也可以进入“单本书籍指定封面”，为历史书籍分别选择专属图片。
3. 返回阅读书籍页查看效果。自定义封面初始关闭；升级保留已有设置。

封面优先级为：**可用原始封面 → 已启用的专属图片 → 已启用的通用图片**。同时存在原始封面和专属关联时显示“原始封面 · 已设专属”，专属图片作为备用。总开关关闭时不使用自定义图片，已有专属关联可显示为“已设置但未启用”。图片只在本机使用，不会改写电子书文件。

Kindle 自带的部分 `No image available` 图片与普通原生缩略图使用相同路径，现有元数据无法可靠区分；这类占位图可能仍按原始缩略图处理。本版未加入不稳定的图像识别算法。

## 下载、安装与升级

下载 Assets 中的 **`Kindle-Reading-Records-v9.8.1-5.20-vera.zip`**。文件名 `5.20` 是环境标签，当前确认的固件是 **5.20.1**，不能据此扩大到全部 5.20 小版本。其他环境请查看 [v9.7.6 的已验证安装包](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.6)。

1. 先备份 Kindle 的 `reading-time` 文件夹。
2. 只解压外层 ZIP 一次，得到 `reading-records-v4-install.sh` 和 `阅读记录安装数据.tar`，将两者一起复制到 Kindle `documents`。**不要继续解压 TAR，也不要下载 GitHub 自动生成的 Source code ZIP 作为安装包。**
3. 安全弹出，在书库点击“安装阅读记录”，等待完成。旧普通版按相同步骤原地升级，无需先卸载或删除旧数据。
4. 打开“阅读记录”，确认历史和新增计时正常，再点击“确认无误之后，再点这个”清理安装文件。

清理不是卸载，保留用户图片、关联、历史、配置和当前运行资源。KS 设备或存在冲突 KS 残留的环境会安全退出。
