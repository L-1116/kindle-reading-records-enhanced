# Kindle 阅读记录 9.7.5兼容版-V2

这是 5.18 / 5.19 兼容性公开测试版。V2 针对部分设备全新安装后“阅读书籍”和“书籍详情”不显示封面的问题作了改善：封面目录在安装时完成初始化，读取 Kindle 书库数据库时兼容缺少可选字段的情况，并加入可按需开启的封面诊断日志。

全新安装或从 V1 覆盖升级均可使用，已有阅读记录和封面缓存会保留。请继续反馈 Kindle 型号、固件版本，以及清空封面缓存和新增书籍后的显示结果。

下载 Release Assets 中的 `kindle-reading-records-v9.7.5-compat-v2.zip`，解压后把全部内容复制到 Kindle USB 根目录，再使用书库中的“阅读记录安装”、KUAL 安装入口或 `;log runme`。不要下载 GitHub 自动生成的 Source code 压缩包。
