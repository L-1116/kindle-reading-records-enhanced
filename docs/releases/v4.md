# Kindle 阅读记录 V4

修复 FBInk 启动兼容性回归，恢复 5.17、5.18.x、5.19.x 的正常启动能力，并保留 Kindle Scribe 5.19.6 触摸兼容修复。

- 取消会误判可用设备的 FBInk 信息命令启动检查；插件在真实绘制时自动选择可用 runtime。
- 保留 5.18.x 首次非闪烁 GC16 刷新、区域刷新降级和周期清屏。
- 绘制 runtime 失败时安全返回 Kindle 书库，释放触摸及防休眠状态。
- 保留两文件安装、覆盖升级、修复、安装失败回滚及历史数据保护。

普通 Kindle 使用 `ReadingTime-V4.zip`；Kindle Scribe 使用 `ReadingTime-V4-KS.zip`。解压外层 ZIP 一次，将 `reading-records-v4-install.sh` 与 `阅读记录安装数据.tar` 一同复制到 Kindle 的 `documents` 文件夹，点击“安装阅读记录”。无需解压 tar。

已有 9.7.4、9.7.5、V1/V2/V3、V3-KS、V4 Test1/Test2 可使用相应版本直接覆盖升级，无需卸载。阅读历史、封面、缓存及用户配置会保留。安装后打开“阅读记录”，确认正常后可点击自动生成的清理安装文件入口。

若出现启动异常，可通过原有支持渠道提供 `/mnt/us/reading-time/launch-last.log`，无需执行命令或选择 runtime。

发布时手动资产仅上传两个用户 ZIP。Full Compatibility、校验和与工程报告不作为公开下载选择。
