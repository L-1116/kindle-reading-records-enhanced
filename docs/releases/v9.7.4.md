# Kindle Reading Records Enhanced v9.7.4

9.7.1 已经建立了从月历和本周统计进入“某日详情”的基础钻取能力。v9.7.4 在此基础上，将插件从单纯的一级统计面板扩展为“概览 → 点击 → 二级详情”的完整阅读统计体系，并加入书籍封面、界面完善和专属启动器图标。

此版本整合并完善了此前 9.7.2 / 9.7.3 测试阶段加入的二级统计与单书详情功能，并已完成 Kindle 实机测试。9.7.1 用户可以直接升级到 v9.7.4，不需要依次安装中间测试版。

## ✨ 主要更新

### 📊 更完整的时间统计

- 点击月历顶部的月份标题，可以进入该月详情；年度统计中的月份柱也会进入同一个月份详情页。
- 月份详情集中展示总阅读时长、阅读天数、阅读日均、阅读书籍数、最高阅读日及其时长。
- 同页提供本月阅读最多的 Top 3 书籍和完整的每日阅读趋势。
- 从“本周”统计摘要可以继续进入最近 8 周趋势，查看连续 8 个自然周的阅读时长变化。
- 8 周页面同时显示本周、上周、较上周变化、8 周平均、最佳一周和本周阅读天数；最右一周为当前周。
- 月份详情和 8 周趋势只在用户点击进入时生成，不会在 Dashboard 启动时预先计算全部二级统计。

### 📚 单本书详情

- 阅读书籍列表中的每本书现在都可以点击，进入独立的单书详情页。
- 顶部显示书籍封面，以及累计阅读时长、阅读天数、首次阅读日期、最近阅读日期、本月阅读时长和 Kindle 当前阅读进度。
- 下方提供完整月份的单书阅读日历，可切换月份；无阅读日期仍保留为空白日期格，时间轴不会断开。
- 点击日历中的日期，可以查看该书当天的具体阅读时长或“未阅读”提示。
- 返回书籍列表后，会恢复进入详情前的近 7 日／本月／今年筛选和原页码。
- 书籍身份优先按稳定 ID 处理：同名但 ID 不同的书不会被误合并，同一 ID 在历史上发生标题变化时仍会归入同一本书。

> 9.7.3 测试版曾使用“活跃日均 + 最近 30 天柱状趋势”的布局；正式版最终改为更适合 Kindle 墨水屏的“本月阅读 + 完整月份阅读日历”。

### 🖼️ 书籍封面

- 阅读书籍列表、某日阅读详情和单书详情均新增书籍封面。
- 阅读书籍列表重新分配了封面、两行书名、阅读时长、当前进度和进度条的空间，并调整为每页 3 本。
- 某日阅读详情同样调整为每页 3 本，保留当天阅读时长和占比。
- 封面只尝试复用 Kindle 本机已有的封面信息与缓存，不联网下载，不扫描整个缩略图目录，也不解析电子书文件。
- 如果 Kindle 本机没有可用封面，页面会安全回退到统一的默认封面；并不保证所有书籍都能获得真实封面。

### 🎨 界面与启动器

- 重做单书详情顶部布局，以左侧封面和右侧 2×3 信息区提升可读性。
- 完善月份趋势、8 周趋势和单书日历的字号、坐标轴、留白、长文本与边界处理。
- 最近 8 周顶部六项统计已按 3×2 网格在卡片内居中，并移除当前周柱子多余的强调外框。
- Kindle 图书馆中的“阅读记录”现在拥有专属启动器图标。安装器会自动部署 SH_Integration 所需的 Scriptlet metadata 和图标资源，并触发 Kindle scanner 更新，用户无需单独配置。

## ⚡ 轻量化与兼容性

- 不新增长期常驻后台进程；tracker daemon 与 9.7.1 保持一致，原有阅读计时机制没有重新设计。
- 月份详情、最近 8 周趋势和单书详情均按需计算，并尽量复用 Dashboard 启动时生成的会话缓存。
- 封面与 Kindle 阅读进度共用一次按需、只读的本地数据库快照，不写入 Kindle 数据库。
- 不改变 `reading-time.tsv` 的原始字段和历史数据格式，也不会在升级时清空阅读记录。
- 不联网获取封面，不全盘扫描封面目录，不引入大型运行库或新的常驻依赖。
- 一级页面切换速度和低 FBInk 调用开销仍是优先目标。

## ⬆️ 从 9.7.1 升级

可以从 `v9.7.1-install-fix` 直接原地升级到 v9.7.4，无需卸载旧版，也无需依次安装 9.7.2 / 9.7.3 测试版。

- 原有 `/mnt/us/reading-time/reading-time.tsv` 阅读历史会保留。
- 已有 `reading-time.tsv.bak`、旧发布目录和现有缓存不会被主动清空。
- 安装器继续使用 staging、原子替换和失败回滚机制。
- 新的二级页面、封面资源和启动器图标会自动部署。
- 不需要重新安装 SH_Integration，用户启动方式不变。

v9.7.4 是完整安装包：全新设备会先完成基础安装，再自动进入 9.7.4 优化安装；已有版本会直接走原地升级路径。

## 📦 安装方法

1. 从本 Release 的 **Assets** 下载 `kindle-reading-records-v9.7.4.zip`。
2. 解压安装包。
3. 将 `RUNME.sh` 和完整的 `native-reading-time-package/` 复制到 Kindle USB 根目录，升级时覆盖同名文件。
4. 安全弹出 Kindle 并断开 USB。
5. 在 Kindle 搜索栏输入：

   ```text
   ;log runme
   ```

6. 等待安装成功提示及图书馆扫描完成，然后打开“阅读记录”。

## 🛡️ 数据安全

- 安装器不会删除或覆盖现有 `reading-time.tsv`。
- 第一次升级时会按既有机制创建历史数据备份；已有备份保持不变。
- daemon、启动器、系统服务配置和新增图标均经过 staging 后发布；安装后半程失败会恢复原文件。
- 每个版本的页面和渲染资源保存在独立 release 目录，旧 release 不会在升级时删除。

尽管安装器已提供保护，升级前仍建议自行备份整个 `/mnt/us/reading-time/` 目录。
