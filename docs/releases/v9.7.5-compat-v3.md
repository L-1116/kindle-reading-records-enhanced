# Kindle 阅读记录 9.7.5 兼容版 V3

建议从本 Release 的 **Assets** 下载 `kindle-reading-records-v9.7.5-compat-v3.zip`。这是完整的安装与原地升级包，支持从 9.7.4、兼容版 V1/V2/V3 升级，也支持全新安装。请勿下载 GitHub 自动生成的 Source code ZIP；它不是 Kindle 安装包。

安装包 SHA-256：`247557cbd8bb80e7c19d28fcdfa7eab08cbd97fcd0e2fa2f976ed21f731999b0`。Release Assets 另附 `SHA256SUMS.txt` 便于核对。

## V3 修复了什么

部分 Kindle 的 catalog 会为同一个 book ID 返回多条记录。旧兼容版遇到第一条记录的 `p_thumbnail`、`p_location` 为空时，会过早停止，因而无法取得后续记录中真实存在的 Kindle 缩略图。结果是已经缓存的旧封面仍能显示，但升级后第一次阅读的新书没有封面。V3 修复了这个 duplicate-row selection 回归：优先选择同 ID 下有可用缩略图和书籍路径的记录，不清理已有封面缓存。

真实问题 Kindle 上，此前无封面的《北平无战事(上下册)》与《平凡的世界》均已在 V3 成功显示新封面。

## “安装文件清理”是什么

V3 将旧的“阅读记录卸载”入口改为一次性的 **“安装文件清理”**。这**不是卸载插件，更不是清空阅读时长数据**。安装或升级完成，并确认“阅读记录”可以正常打开后，点击一次“安装文件清理”，它只删除本插件在安装和封面排查过程中留下的杂文件：USB 根目录的安装包与安装说明、书库中的安装/封面诊断入口、相应 KUAL 安装/调试扩展、临时脚本和明确命名的安装/诊断报告。清理工具最后还会删除自己的书库入口。

这样插件保持干净、轻量：书库中与本插件相关的长期入口只剩 **“阅读记录”**，USB 根目录不再散落安装/调试文件。清理器使用[明确路径白名单](https://github.com/L-1116/kindle-reading-records-enhanced/blob/v9.7.5-compat-v3/native-reading-time-package/cleanup-manifest.txt)，先检查当前 V3 安装是否正常，再检测并删除；若验证失败，会保留安装包并中止。

它**不会**停止插件、删除正在运行的主程序、阅读历史、统计记录、`user.conf`、`book-cover-cache.tsv`、`book-cover-misses.tsv`、`book-covers/` 中的封面、备份或旧 release。若以后需要再次安装或升级，只需重新解压完整 ZIP。清理结果写入插件内部的 `/mnt/us/reading-time/cleanup-last.log`，不会在书库生成新的结果文档。清理功能已在真实 Kindle 上机验证。

## 下载与安装

1. 下载 Assets 中的 `kindle-reading-records-v9.7.5-compat-v3.zip`，将**全部内容**解压到 Kindle USB 根目录。
2. 安全弹出 Kindle，在书库点击“阅读记录安装”；也可通过 KUAL → 阅读记录 → 安装 / 升级，或搜索栏执行 `;log runme`。
3. 确认“阅读记录”可以正常打开，原有时长和封面仍在，新书封面也能显示。
4. 点击“安装文件清理”，清除安装及调试杂文件。完成后仅保留正常的“阅读记录”书库入口。

安装/升级不会主动清空阅读历史和封面缓存。建议在升级前备份 `/mnt/us/reading-time/`。不同 Kindle 型号与固件仍可能有差异，遇到问题请提供机型、固件版本及 `/mnt/us/reading-time/` 内相关诊断信息。
