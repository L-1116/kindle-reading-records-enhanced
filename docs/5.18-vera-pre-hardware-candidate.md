## Firmware detection / gate

`read_firmware()` 和来源选择控制流原样保留：

1. `/etc/prettyversion.txt` 唯一解析成功即使用，独立 `/etc/version.txt` 不参与表决。
2. primary 缺失、不可读或没有可解析版本才 fallback 到 version.txt。
3. 被选中来源存在多个不同版本，安全拒绝；primary 歧义不得借 fallback 绕过。
4. 唯一有效 primary 属于目标外固件时拒绝，不借 fallback 改选。
5. 只允许 `5.18.<纯数字 patch>`，允许更多纯数字 dotted patch 层级；5.18.0、5.18.1、5.18.4、5.18.10、5.18.4.1 均可解析。不是字符串大小比较，没有跨固件排序依赖。
6. 拒绝 5.17、5.19、5.20、5.180、缺 patch、畸形 patch、附着乱码和歧义来源。保持原 Scribe/KS 名称、笔输入、大屏及已安装 KS 标记排除。

计划支持范围为 **5.18.x + Vera 的 Standard Kindle**，没有加入 KS、Scribe 或额外 jailbreak 环境适配。Vera runtime 假设仍是原 KMC FBInk 与设备 Lua；没有新加 jailbreak 探测器。本轮没有设备两版本文件的原始采样，带 Kindle/build/Firmware Version 前缀、引号和 CRLF 的 fixtures 用于验证文本结构，不冒充真实设备证据。

## 待真机观察项与 Release blocker

1. KPW6 5.18.4 + Vera：首次进入正常、连续点击流畅、GC16 首刷和周期清屏无卡住；观察刷新/残影。
2. **横屏阅读 → 打开阅读记录 → 正常进入 → 正常退出 → 恢复原横屏方向。** L/R 两向、重复进入、运行失败后的统一恢复；未经真机通过仍是 Release blocker。
3. LIPC orientationLock 可读取/切换/恢复，Library 打开时序、framebuffer geometry 和触摸坐标同步；preventScreenSaver、eatTapMode 恢复原值。
4. 实体电源键、退出后原生触摸和自动休眠正常。POSIX trap 无法保证 SIGKILL、断电或 LIPC 永久不响应时恢复。
5. 实际 Vera KMC FBInk/Lua 是否完整可执行；本轮不因旧环境白屏而主动增加二进制候选或 ABI 门槛。
6. fresh / 9.7.4 / 9.7.5 / V3 / 同版 reinstall / repair 的实际安装，空间提示、Upstart PID 输出、rollback/recovery 和数据保留。离线执行 MSYS sh/dash 与 host tar/du/cksum，不声称已运行 Kindle BusyBox ash。
