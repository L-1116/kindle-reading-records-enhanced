# KPW firmware 5.19.x 真机验收清单

当前是本地真机候选包，不是已经通过设备验证的公开版本。本清单由项目拥有者执行；普通用户安装说明不包含探测命令、二进制测试或 runtime 选择。

- [ ] 1. 确认设备 firmware 为 5.19.x，记录 KPW 型号与版本。
- [ ] 2. 升级前截图累计时长、“全部”与阅读书籍，记录历史条数及最近日期。
- [ ] 3. 通过 USB 备份 `reading-time/reading-time.tsv`；建议同时复制原有 `.bak`、`user.conf`、两个封面 TSV 和 `book-covers/`。
- [ ] 4. 解压本地 ZIP 一次，把其中两个文件一起复制到 `documents/`，点“安装阅读记录”。
- [ ] 5. 确认出现“阅读记录”和“安装好之后，确认无误了再点这个”，没有要求合并目录或执行命令。
- [ ] 6. 打开阅读记录，确认升级前后的历史连续，累计值符合正常阅读增量。
- [ ] 7. 覆盖周统计、每日时长/月历、阅读书籍、累计时长。周统计属于累计时长中的周视图，沿用基线布局。
- [ ] 8. 点击一个有数据的日期，进入日期详情并返回。
- [ ] 9. 点击月份，进入月份详情并返回。
- [ ] 10. 打开最近 8 周并返回。
- [ ] 11. 点击书籍，检查书籍详情、进度和单书月历，切换月份并返回。
- [ ] 12. 在阅读书籍/累计时长测试“全部”，并切换最近 7 天、本月、今年；确认每页 3 本及分页。
- [ ] 13. 新加入一本文内有封面的 EPUB 与 MOBI，阅读产生记录后检查封面；旧书缓存封面仍在。
- [ ] 14. 检查有 Kindle thumbnail 的 PDF；没有缩略图的 PDF 应显示默认封面。
- [ ] 15. 插件启动前按实体电源键，确认休眠/唤醒正常。
- [ ] 16. 横屏阅读一本书，保持横屏退出书籍。
- [ ] 17. 在这个状态打开阅读记录，确认临时转为竖屏，所有点击位置正确，四个统计视图/详情能正常运行。
- [ ] 18. 用左上角正常退出阅读记录，确认恢复原横屏；再次进入原书核对阅读方向偏好。
- [ ] 19. 分别核对左/右横屏方向，重复横屏进入与退出；不得永久留下竖屏。
- [ ] 20. 插件运行中按实体电源键，检查休眠/唤醒及界面、触摸是否正常。
- [ ] 21. 插件退出后再次按实体电源键，确认休眠/唤醒正常，自动休眠也正常，没有 preventScreenSaver 残留。
- [ ] 22. 连续启动并退出阅读记录 5 次，检查没有空白页、旧触摸进程或方向累积异常。
- [ ] 23. 确认以上全部正常后，最后点“安装好之后，确认无误了再点这个”。
- [ ] 24. 书库长期只保留正式“阅读记录”，两个安装文件和清理入口消失；用户书籍保留。
- [ ] 25. 清理后再次打开阅读记录，确认历史、封面、统计、详情和电源键仍正常。

仅由开发维护者在受控条件下验证 Lua/FBInk/touch 初始化失败与 INT/TERM/HUP；普通用户不承担此类故障注入。可保留 `reading-time/install-last.log` 和 `dashboard-launch.log` 供售后分析，不在书库生成诊断/测试入口。

**发布阻断条件：第 16–19 项横屏完整链路未经 KPW 5.19 真机通过，不得 tag、Release 或宣称发布就绪。** 离线 LIPC/FBInk 模拟只能证明控制流，不能证明实际旋转、电源键、电纸屏刷新或固件对系统属性的行为。
