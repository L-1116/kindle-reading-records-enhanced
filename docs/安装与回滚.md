# Kindle 阅读记录安装与回滚

当前正式安装版为 [`v9.7.4`](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.4)。这是完整安装包，既可用于全新安装，也可从 `v9.7.1-install-fix` 等已有版本直接原地升级。

## 9.7.4 说明

阅读书籍与某日详情统一为每页三本的封面条目。封面解析只使用本机数据：先查 `/mnt/us/reading-time/book-cover-cache.tsv`，失效或缺失时复用一次会话一次的 `cc.db` 只读快照，根据 `p_cdeKey` 取得 `p_thumbnail`；路径仅接受 `/mnt/us/system/thumbnails/` 与 `/mnt/us/system/bookcovers/` 下仍存在的文件。EBOK 可再检查确定命名路径，最后显示内置黑白默认封面。不会扫描 thumbnail 目录、联网或解析电子书。

单书详情为左侧封面、右侧 2×3 指标，下方显示一个完整月份的单书阅读日历。日历按 `book_no + date` 从会话级 `DAY_BOOKS` 聚合，直接复用总月历的 0、30 分钟、1/2/3/4 小时灰度边界；可切换月份，点击日期只更新卡片内的小提示，点击日历空白可取消。

最近 8 周顶部六项采用等宽居中的 3×2 网格；`-12小时58分钟`、`13小时17分钟`、`3小时11分钟` 已纳入离线布局回归。

文档库启动器使用 `阅读记录.sh` 开头的 SH_Integration `Name`、`Author`、`Icon` 元数据，图标固定安装到 `/mnt/us/reading-time/assets/launcher-icon.png`。同一文件也保存在 `/mnt/us/reading-time/releases/9.7.4/assets/` 中；安装器先原子发布共享图标，再替换启动器，最后复用 Kindle full scan。若后续步骤失败，旧图标（如有）和旧启动器会一起恢复；从无图标版本升级失败时会移除新图标并重新扫描。

## v9.7.3-测试版说明

阅读书籍页的五行现在可以进入统一的单书详情页。页面按需展示累计阅读、阅读天数、首次/最近阅读、活跃日均、本月阅读、现有 Kindle 阅读进度与最近 30 天趋势；返回后仍停留在进入前的近 7 日/本月/今年筛选和原页码。

单书详情以本次 Dashboard 会话内的 `book_no` 为主要身份。启动期原有的单次缓存扫描只为 `DAY_BOOKS` 追加 `id` 和 `book_no` 两列，前三列语义和顺序不变；点击后由 `get_book_detail` 单次读取该会话缓存，同时生成所有单书指标及包含零值的连续 30 天序列。它不会重读原始 `reading-time.tsv`，也不新增数据库、常驻进程或永久统计缓存。

## v9.7.2-测试版说明

测试版基于 `v9.7.1-day-detail` 小步增加月份详情和最近 8 周趋势。阅读 daemon、计时规则、`reading-time.tsv` 格式、启动期缓存聚合、热力阈值与一级页面布局均未改变；新统计仅在点击入口后读取本次会话的小型聚合文件。

## 月历选中状态

- `today_date` 只保存插件启动时的真实系统日期。
- `selected_date` 始终保存完整 `YYYY-MM-DD`，首次进入默认等于 `today_date`。
- 月历粗边框只比较 `cell_date == selected_date`；热力填充仍只由该日原始秒数决定。
- 点击新日期会离屏重绘完整月历与快速预览，再做一次既有区域刷新，因此旧格恢复 2 px、新格得到 4 px 内向边框，不会留下双框。
- 切换月份时将 `selected_date` 设为目标月 1 日，杜绝只比较日号导致的“8月11日也被当作9月11日”问题。

热力阈值保持 v9.6.10 原样：0、30分钟、1小时、2小时、3小时、4小时六个边界，对应灰度 255、235、210、180、145、105、70。选中不会改写灰度或文字黑白。

## 当天阅读详情

统一入口为 `open_day_detail(date, source)`，统一聚合为 `get_day_detail(date)`。后者只读取启动时已经一次性生成的 `DAYS` 和 `DAY_BOOKS` 会话缓存，不扫描原始历史日志。

页面展示完整日期、星期、总时长、书籍数，以及每本书的当天时长和占比。书籍按当天秒数降序；同秒数时按标题稳定排序。比例在总时长大于 0 时四舍五入为整数百分比，0 分钟时不计算比例。

列表固定每页 3 本，超过后显示上一页、页码和下一页；页面切换只重绘列表卡片。无数据日期仍可进入，显示“0分钟”“0本”和“当日暂无阅读记录”。

入口包括：

- 月历下方快速预览标题整行的大触摸区；
- 已选日期格再次点击；
- 周视图七个柱/日期对应的纵向触摸区（仅“本周”模式，年度图不响应）。

返回时按 `day_detail_source` 恢复月历或累计时长页。月历的 `selected_date`、当前年月和快速预览不重置；周视图的 `week_offset` 与周/年状态不重置。

## 时间区间详情

通用入口 `get_period_stats(start_date, end_date[, need_books])` 在一次遍历中得到总时长、阅读天数、阅读日均、书籍数、最高阅读日、每日时长和书籍排序数据。它只读取启动时生成的 `DAYS` / `DAY_BOOKS` 会话缓存；8 周页传入 `need_books=0`，不会读取不需要的书籍缓存。

月份详情可从月历顶部月份标题或年度视图月份柱进入同一个 `open_month_detail(year, month, source)` 路径。页面按需展示核心指标、Top 3 和每日柱状趋势；无数据月份只显示简洁空状态。返回会保留原月历年月、选中日期或年度视图状态。

最近 8 周趋势从“本周总时长”区域进入。页面显示 8 个自然周、本周/上周/差值、8 周平均、最佳一周和本周阅读天数；六项指标以 3×2 网格在卡片内居中，所有周柱采用一致样式，不再给当前周增加额外外框。上周为零时只显示绝对时长差，不做百分比除法。返回保留此前周视图及 `week_offset`。

## 安装 9.7.4 正式版

> **必须下载 Assets 中的 `kindle-reading-records-v9.7.4.zip`。**
> 不要下载 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`；它们不是 Kindle 安装包。

1. 退出 Kindle 上的“阅读记录”，USB 连接电脑。
2. 从 [`v9.7.4` Release](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.4) 下载并解压 [`kindle-reading-records-v9.7.4.zip`](https://github.com/L-1116/kindle-reading-records-enhanced/releases/download/v9.7.4/kindle-reading-records-v9.7.4.zip)，然后将 `RUNME.sh` 和完整 `native-reading-time-package/` 复制到 Kindle USB 根目录。
3. 安全弹出 Kindle，在搜索栏执行 `;log runme`。

`RUNME.sh` 会自动判断全新安装或原地升级。9.7.1 用户不需要卸载旧版，也不需要依次安装 9.7.2 / 9.7.3；安装器会发布到 `/mnt/us/reading-time/releases/9.7.4/`，保留阅读历史、`book-cover-cache.tsv`、备份和旧发布目录。安装后如果图书馆中没有出现“阅读记录”，请连接电脑查看 `/mnt/us/reading-time/install.log`。

## 如需回滚到 v9.7.1-install-fix

从 [`v9.7.1-install-fix` Release](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.1-install-fix) 下载 `Kindle-Reading-Records-v9.7.1-install-fix.zip`，解压后复制其中的 `RUNME.sh` 和完整 `native-reading-time-package/` 到 Kindle USB 根目录，覆盖同名项，安全弹出后再次执行 `;log runme`。

不要删除或替换 `/mnt/us/reading-time/reading-time.tsv`。回滚 UI 不需要回滚阅读历史。
