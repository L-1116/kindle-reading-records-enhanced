# Kindle 阅读记录安装与回滚

当前稳定安装版为 [`v9.7.1-install-fix`](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.1-install-fix)，功能内容与 `v9.7.1-day-detail` 一致，仅修复全新用户的安装流程。`v9.7.3-测试版` 是测试版本，不作为默认推荐安装版本。

## v9.7.3-测试版说明

阅读书籍页的五行现在可以进入统一的单书详情页。页面按需展示累计阅读、阅读天数、首次/最近阅读、活跃日均、本月阅读、现有 Kindle 阅读进度与最近 30 天趋势；返回后仍停留在进入前的近 7 日/本月/今年筛选和原页码。

单书详情以本次 Dashboard 会话内的 `book_no` 为主要身份。启动期原有的单次缓存扫描只为 `DAY_BOOKS` 追加 `id` 和 `book_no` 两列，前三列语义和顺序不变；点击后由 `get_book_detail` 单次读取该会话缓存，同时生成所有单书指标及包含零值的连续 30 天序列。它不会重读原始 `reading-time.tsv`，也不新增数据库、常驻进程或永久统计缓存。

## v9.7.2-测试版说明

测试版基于 `v9.7.1-day-detail` 小步增加月份详情和最近 8 周趋势。阅读 daemon、计时规则、`reading-time.tsv` 格式、启动期缓存聚合、热力阈值与一级页面布局均未改变；新统计仅在点击入口后读取本次会话的小型聚合文件。

## 月历选中状态

- `today_date` 只保存插件启动时的真实系统日期。
- `selected_date` 始终保存完整 `YYYY-MM-DD`，首次进入默认等于 `today_date`。
- 月历粗边框只比较 `cell_date == selected_date`；热力填充仍只由该日原始秒数决定。
- 点击新日期会离屏重绘完整月历与快速预览，再做一次既有区域刷新，因此旧格恢复 2 px、新格得到 4 px 内向边框，不会留下双框。
- 切换月份时将 `selected_date` 设为目标月 1 日，杜绝只比较日号导致的“8月11日也被当作9月11日”问题。

热力阈值保持 v9.6.10 原样：0、30分钟、1小时、2小时、3小时、4小时六个边界，对应灰度 255、235、210、180、145、105、70。选中不会改写灰度或文字黑白。

## 当天阅读详情

统一入口为 `open_day_detail(date, source)`，统一聚合为 `get_day_detail(date)`。后者只读取启动时已经一次性生成的 `DAYS` 和 `DAY_BOOKS` 会话缓存，不扫描原始历史日志。

页面展示完整日期、星期、总时长、书籍数，以及每本书的当天时长和占比。书籍按当天秒数降序；同秒数时按标题稳定排序。比例在总时长大于 0 时四舍五入为整数百分比，0 分钟时不计算比例。

列表按可用高度计算为每页 4 本，超过后显示上一页、页码和下一页；页面切换只重绘列表卡片。无数据日期仍可进入，显示“0分钟”“0本”和“当日暂无阅读记录”。

入口包括：

- 月历下方快速预览标题整行的大触摸区；
- 已选日期格再次点击；
- 周视图七个柱/日期对应的纵向触摸区（仅“本周”模式，年度图不响应）。

返回时按 `day_detail_source` 恢复月历或累计时长页。月历的 `selected_date`、当前年月和快速预览不重置；周视图的 `week_offset` 与周/年状态不重置。

## 时间区间详情

通用入口 `get_period_stats(start_date, end_date[, need_books])` 在一次遍历中得到总时长、阅读天数、阅读日均、书籍数、最高阅读日、每日时长和书籍排序数据。它只读取启动时生成的 `DAYS` / `DAY_BOOKS` 会话缓存；8 周页传入 `need_books=0`，不会读取不需要的书籍缓存。

月份详情可从月历顶部月份标题或年度视图月份柱进入同一个 `open_month_detail(year, month, source)` 路径。页面按需展示核心指标、Top 3 和每日柱状趋势；无数据月份只显示简洁空状态。返回会保留原月历年月、选中日期或年度视图状态。

最近 8 周趋势从“本周总时长”区域进入。页面显示 8 个自然周、本周/上周/差值、8 周平均、最佳一周和本周阅读天数；当前周仅增加黑色粗边框，不覆盖原柱体灰度。上周为零时只显示绝对时长差，不做百分比除法。返回保留此前周视图及 `week_offset`。

## 修改范围

- `native-reading-time-package/阅读记录-optimized.sh`：通用区间聚合、月份详情、8 周趋势、共享入口与状态恢复。
- `native-reading-time-package/reading-insights-touch-ui.lua`：月份标题、年度月份、本周摘要和二级页返回热区。
- `native-reading-time-package/ui-calendar/month_detail.png`、`week_trend.png`、`book_detail.png`：Kindle 黑白二级页背景。
- `native-reading-time-package/render-assets/dynamic-glyphs.*`：只补充新页面所需静态字形。
- `native-reading-time-package/reading-insights-cache.awk`：仅为会话级 `DAY_BOOKS` 追加稳定身份列，不改变原始数据。
- `native-reading-time-package/Install-Native-Reading-Time-Optimized.sh`：发布目录、版本标记与资源检查更新到 v9.7.3-测试版。
- `scripts/`、`tests/`：资源构建、旧回归、新功能回归、隔离安装和打包校验。

`native-reading-time-daemon.sh`、`native-reading-time.conf`、`阅读记录.sh`、`reading-insights-touch.lua` 与 v9.6.10 字节一致；`reading-insights-cache.awk` 只有上述会话输出列扩展。

## 离线验证

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate_all.py
```

结果分别写入 `build/validation/`，安装包写入 `dist/`。PNG 可以验证离屏布局与精确灰度，但电子墨水残影和触摸手感仍需 Kindle 实机确认。

## 安装稳定版

> **首次安装必须下载 Assets 中的 `Kindle-Reading-Records-v9.7.1-install-fix.zip`。**
> 不要下载 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)`；它们不是 Kindle 安装包。

1. 退出 Kindle 上的“阅读记录”，USB 连接电脑。
2. 从 [`v9.7.1-install-fix` Release](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.1-install-fix) 下载并解压 [`Kindle-Reading-Records-v9.7.1-install-fix.zip`](https://github.com/L-1116/kindle-reading-records-enhanced/releases/download/v9.7.1-install-fix/Kindle-Reading-Records-v9.7.1-install-fix.zip)，然后将 `RUNME.sh` 和完整 `native-reading-time-package/` 复制到 Kindle USB 根目录。
3. 安全弹出 Kindle，在搜索栏执行 `;log runme`。

该安装包同时支持全新安装和旧版升级，`RUNME.sh` 会自动判断安装路径。安装后如果图书馆中没有出现“阅读记录”，请连接电脑查看 `/mnt/us/reading-time/install.log`。

## 安装测试版

使用 `kindle-reading-records-v9.7.3-test.zip`，解压后按上述相同步骤复制并安装。安装器会发布到 `/mnt/us/reading-time/releases/9.7.3-测试版/`，保留阅读历史、备份和旧发布目录。

## 回滚到稳定版 v9.7.1-install-fix

从 [`v9.7.1-install-fix` Release](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.1-install-fix) 下载 `Kindle-Reading-Records-v9.7.1-install-fix.zip`，解压后复制其中的 `RUNME.sh` 和完整 `native-reading-time-package/` 到 Kindle USB 根目录，覆盖同名项，安全弹出后再次执行 `;log runme`。

不要删除或替换 `/mnt/us/reading-time/reading-time.tsv`。回滚 UI 不需要回滚阅读历史。
