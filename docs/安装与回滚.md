## 两文件安装、原地升级与备用包

1. **先备份 Kindle 的 `reading-time` 文件夹**，保留阅读历史、配置和封面。
2. 按上表选择 **一个安装 ZIP**。5.20 Vera 优先 test12；5.19 Vera 使用专用包。首次安装需要选用旧版，或推荐包安装失败并已自动恢复旧版本时，可再按设备选择 test11 或 test10 备用包。
3. **只解压外层 ZIP 一次**，得到 `reading-records-v4-install.sh` 与 `阅读记录安装数据.tar`，将两者一起复制到 Kindle `documents`，覆盖同名安装文件；**不要继续解压 TAR，不要混用不同包的脚本和 TAR**。
4. 安全弹出 Kindle，在书库点击“安装阅读记录”，等待完成。旧 Standard 普通版可按相同步骤原地覆盖安装，无需先卸载或删除历史数据。
5. 打开“阅读记录”，确认历史、封面和新增计时正常后，再点击“确认无误之后，再点这个”清理安装文件。

**备用包同样要从该 ZIP 重新复制完整的两份配套文件。已成功安装 test12 的设备，test11／test10 原包会因版本归属保护拒绝直接降级；此时请保留当前安装与数据，通过 Issues 寻求支持，不要手动删除入口或绕过校验。** 清理不是卸载；不要手动清空 `reading-time`。test12 的安装报告与自动安装诊断保存在 `reading-time/install-logs/`，避免进入书库；test10、test11 仍保留旧报告行为。

Assets 中提供四个安装 ZIP，显示名称标明推荐或备用；下载后的文件名以 `recommended` 标注推荐包、`backup` 标注备用包。GitHub 自动生成的 **Source code (zip)** 与 **Source code (tar.gz)** 是源码下载，**不是 Kindle 安装包**。

安装成功后已有 `reading-time/custom-covers/` 图片目录，无需先开启封面开关。升级和清理保护用户历史、图片、专属关联、配置、当前运行资源和必要回滚材料；无法确认归属的内容保留。

失败时保留原安装文件和备份，通过 [Issues](https://github.com/L-1116/kindle-reading-records-enhanced/issues) 说明机型、固件、越狱方式、所用 ZIP 和错误现象。异常日志用于售后支持，普通用户无需执行命令或选择 runtime。

## 兼容版 V3 安装与数据保护

V3 安装到 `/mnt/us/reading-time/releases/9.7.5-test/`，不会删除 9.7.4 发布目录、`reading-time.tsv`、设置、备份或既有 `book-cover-cache.tsv`。新增的本体封面写入 `/mnt/us/reading-time/book-covers/`，失败签名写入 `book-cover-misses.tsv`；两者都按需生成。回滚到旧启动器时历史数据不受影响。V3 修复了同一 book ID 多条 catalog 记录时，第一条空的缩略图/书籍路径遮蔽后续有效记录、导致新书无封面的回归。

将 ZIP 全部内容解压到 Kindle USB 根目录，然后通过书库中的“阅读记录安装” Scriptlet、KUAL 的“阅读记录 → 安装 / 升级”或旧的 `;log runme` 安装。三者最终都调用 `/mnt/us/native-reading-time-package/install.sh`，安装后的书库入口只调用 `/mnt/us/reading-time/bin/launch.sh`。安装后先确认“阅读记录”能正常打开，再运行“安装文件清理”。launcher 负责环境、依赖、数据与 UI 检查；失败会记录阶段和退出码并生成 `documents/reading-records-diagnostic.txt`。

## 安装文件清理：不是卸载

同一 ZIP 内的 `documents/reading-records-uninstall.sh` 在 SH Integration 书库中显示为**“安装文件清理”**。保留旧 ASCII 文件名只为覆盖旧版“卸载”入口；V3 不再提供卸载程序的动作。清理入口和 KUAL 中的同名动作都只执行经过安全标记验证的清理核心：

```text
安装文件清理 Scriptlet ─┐
KUAL 安装文件清理 ──────┼─> /tmp 中的副本 ─> native-reading-time-package/uninstall.sh
旧动作兼容别名 ─────────┘
```

清理前先验证当前 V3 主程序、launcher、书库入口和服务配置确实存在，安装包与已安装 resolver 一致；若无法确认，则中止并保留安装包。脚本先检测所有候选目标，再仅删除 [`cleanup-manifest.txt`](../native-reading-time-package/cleanup-manifest.txt) 中列出的确切路径。清理内容限于安装报告、封面调试报告与入口、安装 Scriptlet/KUAL、安装包及旧清理入口。运行中的清理核心已复制到 `/tmp`，所以可以最后自删；完成后只请求 Kindle scanner 刷新，不重启设备。

**不会删除：** `/etc/upstart/native-reading-time.conf`、`documents/阅读记录.sh`、当前与旧版 `reading-time/releases/`、运行所需的 `bin/compat/ui/fonts/assets`、daemon、阅读历史、统计、配置、封面缓存、已有封面、备份及其他未列入白名单的文件。不会停止服务，也不会卸载 Reading Time。

**会删除：** 安装完成后不再使用的 `/mnt/us/native-reading-time-package/`、根目录安装说明与 RUNME、书库中的“阅读记录安装”“阅读记录封面诊断”“安装文件清理”、相应 KUAL 安装/诊断扩展及明确命名的安装/诊断报告。清理后本插件在书库中长期只留“阅读记录”。若以后需要重新安装或升级，请重新解压完整 ZIP；原阅读数据仍在。

执行结果只写入 `/mnt/us/reading-time/cleanup-last.log`，不会生成新的书库可见文档。已不存在的目标按 `SKIP` 处理，可安全重复执行。安装目录若混入不属于包的文件，会在删除前中止，避免误删用户内容。

PDF 仅使用 Kindle 已有 thumbnail/bookcover，不包含 PDF 页面渲染器。EPUB 本体提取依赖设备已有的 `unzip` 命令；缺少命令或文件异常时直接显示默认封面。MOBI 由随包的小型 Lua helper 解析，不引入第三方库。

## 9.7.4 说明

阅读书籍与某日详情统一为每页三本的封面条目。封面解析只使用本机数据：先查 `/mnt/us/reading-time/book-cover-cache.tsv`，失效或缺失时复用一次会话一次的 `cc.db` 只读快照，根据 `p_cdeKey` 取得 `p_thumbnail`；路径仅接受 `/mnt/us/system/thumbnails/` 与 `/mnt/us/system/bookcovers/` 下仍存在的文件。EBOK 可再检查确定命名路径，最后显示内置黑白默认封面。不会扫描 thumbnail 目录、联网或解析电子书。

单书详情为左侧封面、右侧 2×3 指标，下方显示一个完整月份的单书阅读日历。日历按 `book_no + date` 从会话级 `DAY_BOOKS` 聚合，直接复用总月历的 0、30 分钟、1/2/3/4 小时灰度边界；可切换月份，点击日期只更新卡片内的小提示，点击日历空白可取消。

最近 8 周顶部六项采用等宽居中的 3×2 网格；`-12小时58分钟`、`13小时17分钟`、`3小时11分钟` 已纳入离线布局回归。

文档库启动器使用 `阅读记录.sh` 开头的 SH_Integration `Name`、`Author`、`Icon` 元数据，但它现在只是统一 launcher 的薄入口；9.7.5 UI 主脚本安装到 `/mnt/us/reading-time/releases/9.7.5-test/bin/reading-records.sh`。图标固定安装到 `/mnt/us/reading-time/assets/launcher-icon.png`，同一文件也保存在版本发布目录。安装器先原子发布共享图标、launcher 与 UI，再替换书库入口，最后复用 Kindle full scan。若后续步骤失败，旧图标、旧入口和旧 launcher 会一起恢复。

## v9.7.3-测试版说明

阅读书籍页的五行现在可以进入统一的单书详情页。页面按需展示累计阅读、阅读天数、首次/最近阅读、活跃日均、本月阅读、现有 Kindle 阅读进度与最近 30 天趋势；返回后仍停留在进入前的近 7 日/本月/今年筛选和原页码。

单书详情以本次 Dashboard 会话内的 `book_no` 为主要身份。启动期原有的单次缓存扫描只为 `DAY_BOOKS` 追加 `id` 和 `book_no` 两列，前三列语义和顺序不变；点击后由 `get_book_detail` 单次读取该会话缓存，同时生成所有单书指标及包含零值的连续 30 天序列。它不会重读原始 `reading-time.tsv`，也不新增数据库、常驻进程或永久统计缓存。

## v9.7.2-测试版说明

测试版基于 `v9.7.1-day-detail` 小步增加月份详情和最近 8 周趋势。阅读 daemon、计时规则、`reading-time.tsv` 格式、启动期缓存聚合、热力阈值与一级页面布局均未改变；新统计仅在点击入口后读取本次会话的小型聚合文件。

## 月历选中状态

- `today_date` 只保存插件启动时的真实系统日期。
- `selected_date` 始终保存完整 `YYYY-MM-DD`，首次进入默认等于 `today_date`。
- 月历粗边框只比较 `cell_date == selected_date`；热力填充仍只由该日原始秒数决定。
- 点击新日期会离屏重绘完整月历与快速预览，再做一次既有区域刷新，因此旧格恢复 2 px、新格得到 4 px 内向边框，不会留下双框。
- 切换月份时将 `selected_date` 设为目标月 1 日，杜绝只比较日号导致的“8月11日也被当作9月11日”问题。

热力阈值保持 v9.6.10 原样：0、30分钟、1小时、2小时、3小时、4小时六个边界，对应灰度 255、235、210、180、145、105、70。选中不会改写灰度或文字黑白。

## 当天阅读详情

统一入口为 `open_day_detail(date, source)`，统一聚合为 `get_day_detail(date)`。后者只读取启动时已经一次性生成的 `DAYS` 和 `DAY_BOOKS` 会话缓存，不扫描原始历史日志。

页面展示完整日期、星期、总时长、书籍数，以及每本书的当天时长和占比。书籍按当天秒数降序；同秒数时按标题稳定排序。比例在总时长大于 0 时四舍五入为整数百分比，0 分钟时不计算比例。

列表固定每页 3 本，超过后显示上一页、页码和下一页；页面切换只重绘列表卡片。无数据日期仍可进入，显示“0分钟”“0本”和“当日暂无阅读记录”。

入口包括：

- 月历下方快速预览标题整行的大触摸区；
- 已选日期格再次点击；
- 周视图七个柱/日期对应的纵向触摸区（仅“本周”模式，年度图不响应）。

返回时按 `day_detail_source` 恢复月历或累计时长页。月历的 `selected_date`、当前年月和快速预览不重置；周视图的 `week_offset` 与周/年状态不重置。

## 时间区间详情

通用入口 `get_period_stats(start_date, end_date[, need_books])` 在一次遍历中得到总时长、阅读天数、阅读日均、书籍数、最高阅读日、每日时长和书籍排序数据。它只读取启动时生成的 `DAYS` / `DAY_BOOKS` 会话缓存；8 周页传入 `need_books=0`，不会读取不需要的书籍缓存。

月份详情可从月历顶部月份标题或年度视图月份柱进入同一个 `open_month_detail(year, month, source)` 路径。页面按需展示核心指标、Top 3 和每日柱状趋势；无数据月份只显示简洁空状态。返回会保留原月历年月、选中日期或年度视图状态。

最近 8 周趋势从“本周总时长”区域进入。页面显示 8 个自然周、本周/上周/差值、8 周平均、最佳一周和本周阅读天数；六项指标以 3×2 网格在卡片内居中，所有周柱采用一致样式，不再给当前周增加额外外框。上周为零时只显示绝对时长差，不做百分比除法。返回保留此前周视图及 `week_offset`。

`RUNME.sh` 会自动判断全新安装或原地升级。9.7.1 用户不需要卸载旧版，也不需要依次安装 9.7.2 / 9.7.3；安装器会发布到 `/mnt/us/reading-time/releases/9.7.4/`，保留阅读历史、`book-cover-cache.tsv`、备份和旧发布目录。安装后如果图书馆中没有出现“阅读记录”，请连接电脑查看 `/mnt/us/reading-time/install.log`。

## 如需回滚到 v9.7.1-install-fix

从 [`v9.7.1-install-fix` Release](https://github.com/L-1116/kindle-reading-records-enhanced/releases/tag/v9.7.1-install-fix) 下载 `Kindle-Reading-Records-v9.7.1-install-fix.zip`，解压后复制其中的 `RUNME.sh` 和完整 `native-reading-time-package/` 到 Kindle USB 根目录，覆盖同名项，安全弹出后再次执行 `;log runme`。

不要删除或替换 `/mnt/us/reading-time/reading-time.tsv`。回滚 UI 不需要回滚阅读历史。
