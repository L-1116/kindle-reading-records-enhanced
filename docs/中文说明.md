# 9.7.6-5.18-springbreak：安装说明

已在**一台 Kindle Paperwhite 4（KPW4，10 代）、固件 5.18.1.1.1、SpringBreak 越狱环境**的机器上运行成功。实机验证范围仅为这台设备及该固件/越狱组合；不据此宣称其他型号或其他 5.18 固件均已通过。

只适用于 **KPW4 / 固件 5.18.1.1.1 / SpringBreak，并且已有 Scriptlet 安装入口**。

1. 将 `ReadingTime-9.7.6-5.18-springbreak.zip` 解压一次。把得到的 `reading-records-9.7.6-install.sh` 和 `reading-records-9.7.6-data.tar` 一起复制到 Kindle 的 `documents` 文件夹。不要继续解压 TAR，也不要删除原有 `reading-time` 文件夹。
2. 安全断开 USB，在书库点击“安装阅读记录”，等待安装完成提示。Test 1 / Test 2 可以直接覆盖升级；历史时长、备份、配置、封面和缓存会保留。不需要先卸载、重新越狱、安装依赖或执行命令。
3. 打开“阅读记录”查看月历、总计和书籍统计。需要退出时点击左上角退出；每次会话也保留约两分钟自动退出保护。

这个版本每次打开约两分钟后会自动退出，即使触摸按钮没有反应也会尝试回到书库。两分钟从 UI 子进程启动算起，包含首次绘制时间；正常清理还需少量时间。先等待，不要反复点击图标或同时重装。自动退出进入原有清理流程，不改变电源键；如果系统 LIPC、内核或前台服务自身卡住，仍不能保证自动恢复。这种情况请停止再次打开，按设备原有方式恢复，不需要执行任何排障命令。

**有任何失败，请保留两个安装文件，不点“安装好之后，确认无误了再点这个”，也不删除整个 `reading-time` 文件夹。** 同一安装入口可再次 repair；事务失败会尽力回滚旧运行文件。恢复失败时安装日志会记录 `RECOVERY_REQUIRED` 和保留的恢复快照，快照请一并留着。若 UI 测试失败，下一步由开发者提供修复或已知版本恢复包，不让你自行替换系统组件。

确认正常后再考虑点击安装清理入口。它只删除安装残留，保留正式“阅读记录”、运行文件、历史和核心日志。

若失败，只需通过 USB 复制 `reading-time` 内这些已有文件给开发者（存在的就复制，无需找齐）：

- `dashboard-launch.log`
- `dashboard-touch.log`
- `display-layout.txt`
- `install-last.log`
- 如果安装/统计服务也异常，再补 `service.log`、`upstart.log`。

售后支持时可简要描述异常现象。**不用提供序列号、账户、书籍正文、整份系统日志或原始触摸事件流。** 默认不需要复制 `state`、统计报告或 `reading-time.tsv`；这些可能含书名。确需补充状态时由开发者另行说明并遮掉无关书籍信息。
